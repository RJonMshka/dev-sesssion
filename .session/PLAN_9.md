## Chunk 9 — Polish, testing completeness & open-source prep

Most of this chunk shipped with v1.0.0 (LICENSE, README, CHANGELOG, SECURITY.md,
CONTRIBUTING.md, `.releaserc.json`, core docs, MIT relicense). The 2026-06-17
follow-up session closed the remaining **doable** items and built the coverage
infrastructure. What's left is either external/manual or a tracked follow-up.

### Done (2026-06-17 follow-up session)

- **Audits run.**
  - Licenses: all third-party prod deps are MIT (license-checker). The only
    `UNLICENSED` hit is the private monorepo root, which is never published.
  - Secrets: `gitleaks detect` found 14 matches — all planted **fake** fixtures
    in `packages/security/src/__tests__/`. Added `.gitleaks.toml` allowlisting
    that test dir → repo now scans clean. Added a gitleaks CI step.
- **Subprocess coverage infrastructure + target met** (the v8/execa gap):
  `c8` + `NODE_V8_COVERAGE` collects coverage from the spawned CLI binary,
  remapped to source via the tsup sourcemap; merged DISJOINTLY with vitest
  in-process coverage (each file credited to exactly one collector — their
  statement maps differ and overlap-merging corrupts %). Then closed the gap
  with +33 lifecycle e2e tests (update/advance/export/import/health/status/
  prompt + warning states) and +20 adapter `formatAiIndex` unit tests. Final:
  **81.94% stmts / 75.67% branches** — CI gate raised to the **80/75 target**
  in `merge-coverage.mjs`. (c8 report needs `--max-old-space-size=8192` to
  remap the ~187 CLI-subprocess dumps; set in `collect-e2e-coverage.mjs`.)
- **Perf benchmark**: `pnpm benchmark:status` — 200-file project, median ~338ms
  (< 500ms budget). Exits non-zero on regression.
- **Docs**: `AUTHORS`, `PROTOCOL.md` (Session Protocol v1.0), and
  `docs/authoring-adapters.md`; README gained a Documentation index and the
  Windsurf adapter was added to the package table.
- **`private`**: kept on `core`/`security`/`adapters` ON PURPOSE — they are
  bundled into the published `cli` via tsup `noExternal`, so they must NOT be
  published independently. Only the CLI package is publishable. Task is
  considered satisfied (the publishable package is public).
