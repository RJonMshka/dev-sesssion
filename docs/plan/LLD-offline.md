# LLD — no network, no API key

**Area:** `OFF` — dev-sesssion runs inside a coding harness (Claude Code,
opencode, Cursor, Windsurf) or a terminal, and never calls a model itself.

Method: [../METHOD.md](../METHOD.md).

---

## Problem

`compact <file>` (`packages/cli/src/commands/compact.ts`) sends a context file
to the Anthropic API (Haiku) and writes back a shorter version. It is the only
command that:

- needs `ANTHROPIC_API_KEY`, separate from whatever harness the user runs;
- performs network egress, which is why `guardEgress()` and a `SECURITY.md`
  section exist;
- pulls in a runtime dependency, `@anthropic-ai/sdk`, that is bundled into the
  single-file npm artifact.

The tool is meant to be used *from* an agent harness. A user who has one
already has a model that can shorten a file, with their own subscription and
their own permissions. A second, separately billed path is a feature nobody is
expected to use, and it makes "the tool is local" an exception-laden claim.
Decision (owner, 2026-10-26): remove it.

## Requirements

**REQ-OFF-1** — The CLI shall not send a request over the network.

**REQ-OFF-2** — The published package shall not depend on a model provider's
SDK.

**REQ-OFF-3** — When the user runs `compact`, the CLI shall exit non-zero and
say that the command was removed and that the harness's agent can shorten the
file instead.

## Design

- Delete `commands/compact.ts`, `__tests__/compact.test.ts`, its
  registration in `cli.ts`, its `.gitleaks.toml` allowlist entry, and the
  `compact` block of `tests/e2e/context-intelligence.e2e.test.ts`.
- Drop `@anthropic-ai/sdk` from `packages/cli/package.json`. The root
  `package.json` keeps it as a dev dependency only while `evals/` still calls
  the API (LLD-agent-tier.md moves that onto `claude -p`).
- REQ-OFF-3 is a hidden Commander command (`{ hidden: true }`), so `--help`
  no longer lists it, but a script or habit that calls it gets a reason rather
  than Commander's bare `unknown command`. It throws `CliError` with exit 1.
  It accepts and ignores any arguments, so `compact CLAUDE.md --yes` gets the
  same message.
- `SessionStateManager.compact` is unrelated (it trims completed-chunk detail
  in `SESSION_STATE.md`) and stays.
- `PROTOCOL.md`'s optional `.session/backups/` stays in the spec: existing
  projects may hold one, and a conforming tool may still write backups.
- Docs: `README.md`, `SECURITY.md`, `docs/commands.md`, `docs/GUIDE.md`,
  `docs/releasing.md`, `evals/RIGOUR.md` (the egress row), `evals/adversarial.ts`.
  `CHANGELOG.md` is generated by semantic-release and is not edited.

**Release.** Removing a command is breaking: the commit is `feat!:` with a
`BREAKING CHANGE:` footer, so the next merge to `main` releases 3.0.0.

## Test plan

| Requirement | Level | Test |
|---|---|---|
| REQ-OFF-1 | e2e | The built bundle contains no `api.anthropic.com` and no `ANTHROPIC_API_KEY` |
| REQ-OFF-2 | unit | `packages/cli/package.json` lists no `@anthropic-ai/sdk`, `openai` or `@google/generative-ai` in `dependencies` |
| REQ-OFF-3 | e2e | `compact CLAUDE.md --yes` exits 1; output says it was removed and names the agent; `--help` does not list it |

## Out of scope

- A harness skill that does what `compact` did. The plan skill shows the shape
  if it is ever wanted; nothing suggests it is.
- The eval agent tier. It is dev tooling, never shipped, and moves to
  `claude -p` under LLD-agent-tier.md.
